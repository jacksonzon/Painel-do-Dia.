PAINEL DO DIA — DRAGON EDITION

Pacote pronto para publicação como PWA.

ARQUIVOS
- index.html
- manifest.json
- sw.js
- src/js/aiBridge.js
- src/js/dragonV9.js

IMPORTANTE
Publique a pasta em um host HTTPS. Depois abra a URL no Safari do iPhone e use:
Compartilhar -> Adicionar à Tela de Início.

O aplicativo salva os dados no localStorage do navegador e possui backup interno.
